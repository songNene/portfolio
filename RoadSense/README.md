# 교통사고 심각도 예측

교통사고 데이터를 활용하여 **사고 심각도에 영향을 미치는 요인 분석 및 사고 심각도를 예측하는 머신러닝 프로젝트**입니다.

## 프로젝트 목적

* 교통사고 데이터의 주요 특성 분석
* 사고 상황과 차량 유형 등의 범주 재정의
* 사고 심각도 예측 모델 구축
* 모델 성능 비교 및 주요 변수 분석

## 데이터

총 4개의 데이터셋으로 구성

| 데이터셋      | 내용         |
| --------- | ---------- |
| Accidents | 교통사고 발생 정보 |
| Places    | 교통사고 장소 정보 |
| Users     | 교통사고 인적 정보 |
| Vehicles  | 교통사고 차량 정보 |

## 분석 과정

**데이터 탐색 → 전처리 → 변수 재정의 → 인코딩 → 모델링 → 검증 및 평가**

### 주요 전처리

* 결측치 처리
* 범주형 변수 통합 및 재정의
* 불필요한 변수 제거
* 범주형 변수 인코딩

### 모델

* Logistic Regression
* XGBoost

### 모델 검증

* 교차검증 (CV)

### 모델 평가

* Recall
* F1
* F2
* ROC-AUC

## 사용 기술

Python · Pandas · NumPy · Scikit-learn · XGBoost · Matplotlib · Seaborn
